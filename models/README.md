# Pasta de Modelos 3D

Esta pasta é reservada para os modelos 3D dos inimigos do jogo "A Décima Ordem" no formato **.glb**.

O carregador busca os modelos usando os nomes dos inimigos normalizados (letras minúsculas, sem acentos e espaços substituídos por sublinhados `_`).

### Arquivos sugeridos pelo plano:
- `goblin.glb`
- `zumbi.glb`
- `lobisomem.glb`
- `dragao.glb`
- `esqueleto.glb`
- `aranha_gigante.glb`
- `golem_de_pedra.glb`
- `troll.glb`
- `mago.glb`
- `espectro.glb`
- `sombra.glb`

Se o arquivo correspondente não estiver presente aqui, o jogo automaticamente gera um modelo 3D procedural dinâmico (estilo Minecraft/Blockbench) em tempo de execução.
